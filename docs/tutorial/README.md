## 动手前：准备环境

版本以仓库根目录的 `mise.toml` 为准（用 [mise](https://mise.jdx.dev/) 管理版本最省心，也可以手动装同版本）：

1. **Git**
2. **Node.js 24.14.0** —— 本仓库的运行时
3. **pnpm 10.33.2** —— 包管理器（monorepo 必需，npm/yarn 装不了这个仓库）

首次初始化（安装依赖 + 准备桌面运行资源 + 构建基础包，需要一些时间）：

```bash
pnpm bootstrap
```

跑起来看看（改代码会热更新，学习期最有用的命令）：

```bash
pnpm dev:web        # 浏览器打开 http://localhost:5173（后端在 3030）
pnpm dev:desktop    # 或者跑 Electron 桌面版
```

## 学习方法建议

- **每章末尾有「动手环节」**——别跳过，跑一遍比读十遍记得牢。
- **两个最常用的验证命令**：`pnpm typecheck`（类型检查）、`pnpm lint`（代码规范检查）。改完任何代码都跑一下，报错信息本身就是最好的教材。
- 本仓库还有三份「规则文档」，读代码遇到设计疑问时去查：
  - `AGENTS.md` —— 仓库工作规范（spec 先行、模块边界）
  - `DESIGN.md` —— UI 设计规范
  - `CONTEXT.md` —— 插件商店领域词汇表
